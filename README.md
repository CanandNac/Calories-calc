# КБЖУ

Трекер КБЖУ на неделю с календарём за год. Веб-приложение в `www/index.html`, в APK оборачивается через Capacitor.

## Как получить APK

1. Создай репозиторий на GitHub и загрузи в него все файлы из этой папки (вместе с папкой `.github`).
2. Открой вкладку Actions. Сборка запустится сама после загрузки, либо нажми Run workflow.
3. Через 5-10 минут открой завершённый запуск и скачай архив `kbzhu-apk` внизу страницы.
4. Распакуй архив, перенеси `app-debug.apk` на телефон и установи (разреши установку из неизвестных источников).

Чтобы изменить приложение, правь `www/index.html` и снова загружай в репозиторий.
